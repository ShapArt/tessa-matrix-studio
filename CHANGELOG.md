# Changelog

## 1.9.7 — 2026-08-27

- исправлено обновление Excel-схемы после сортировки и overwrite существующей строки;
- `mergeWorkbookIntoCurrentSnapshot()` теперь сопоставляет повторяющуюся identity источника с пропавшей identity цели по тем же правилам, что основной planner;
- regression подтверждает, что schema refresh сохраняет исходные A/C и переносит копию только в целевую B.
## 1.9.6 — 2026-08-27

- исправлена зависимость сопоставления от порядка строк при сортировке Excel и копировании существующей строки поверх другой;
- planner теперь определяет overwrite по повторяющейся identity источника и пропавшей identity цели, а позицию использует только как дополнительное доказательство;
- добавлен regression-сценарий A/B/C → сортировка C/A/B → копирование A поверх B без лишнего ADD/DELETE/SKIP.

## 1.9.5 — 2026-08-27

- исправлена рассинхронизация версии: runtime `APP.version` теперь совпадает с `@version` userscript;
- корректная версия отображается в панели Studio, Excel-инструкции и автоматическом error-report;
- smoke regression автоматически проверяет, что внутренняя версия больше не может отстать от metadata.

## 1.9.4 — 2026-08-27

- security/packaging release без изменений бизнес-логики и пользовательского поведения TESSA Matrix Studio;
- release pipeline публикует `SHA256SUMS.txt` для `.user.js` и ZIP;
- release assets получают GitHub/Sigstore provenance-аттестацию после успешных Tests и CodeQL;
- релиз собирается из того же commit SHA, который прошёл `Quality & Security`.

## 1.9.3 — 2026-08-27

- добавлен end-to-end acceptance regression suite для `NOOP / PATCH / ADD / REPLACE / DELETE / SKIP / stale preview / справочников / отмены`;
- исправлена классификация ошибок справочника: слово «справочник» больше не распознаётся как ошибка прав из-за подстроки «прав»;
- `npm test` теперь включает пользовательские acceptance-сценарии поверх planner и preflight.

## 1.9.2 — 2026-08-27

- `@updateURL` и `@downloadURL` переведены с `raw.githubusercontent.com` на jsDelivr, чтобы автообновление и повторная установка не зависели от GitHub Raw;
- версия README, `package.json` и regression tests синхронизирована с userscript.

## 1.9.1 — 2026-08-26

Пользовательский релиз TESSA Matrix Studio.

- добавлен основной домен `tessa.cherkizovsky.net`;
- исправлено сопоставление копий и сценарий замены строки поверх существующей;
- сохранено штатное удаление строк при реальном удалении строки из Excel;
- добавлены progress bar и этапы длительных операций;
- убрано всплывающее сообщение Excel «Поиск в словаре TESSA»;
- переименованы технические кнопки в понятные пользовательские действия;
- добавлена повторная проверка перед применением и защита от опасных удалений;
- обновлены комментарии и структура production userscript;
- подготовлена единая пользовательская инструкция в `README.md`;
- добавлены реальные скриншоты Studio и реальной Excel-выгрузки;
- установка переведена на jsDelivr с GitHub Release как резервным способом;
- добавлены CI, regression tests и CodeQL.

## 1.9.0

- добавлено действие `ЗАМЕНИТЬ` для вставки копии поверх существующей строки;
- добавлен пошаговый UI и индикатор прогресса;
- переработана инструкция Excel.

## 1.8.6

- исправлено ложное удаление при копировании строки с повторяющимися служебными ID;
- добавлена защита от неявного удаления при конфликте identity.
