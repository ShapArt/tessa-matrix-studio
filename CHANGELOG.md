# Changelog

## 1.9.1

Пользовательский релиз и перенос в отдельный репозиторий.

- автор изменён на **Шаповалов Артём**;
- metadata переведена на `ShapArt/tessa-matrix-studio`;
- добавлены ссылки для установки и автообновления;
- код разбит комментариями на функциональные разделы;
- пользовательский файл ошибки переименован в `TESSA_Matrix_ErrorReport_*.json`;
- добавлена полная GitHub-документация по установке, правам и работе;
- добавлены иллюстрации интерфейса и сценариев Excel;
- пользовательский релиз очищен от временных и служебных материалов разработки.

## 1.9.0

- добавлена операция **ЗАМЕНИТЬ** при вставке строки поверх существующей;
- добавлен `https://tessa.cherkizovsky.net/*`;
- переработана инструкция Excel;
- добавлен progress UI;
- уточнены кнопки обновления справочников и структуры Excel;
- сохранены safety-проверки удаления, дублей и неоднозначных значений.
