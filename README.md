# TESSA Matrix Studio

**Excel-редактор матриц согласования TESSA для Группы Черкизово.**

TESSA Matrix Studio добавляет в карточку матрицы компактную панель: матрицу можно выгрузить в Excel, изменить привычными средствами, проверить точный список изменений и только после этого записать их обратно в TESSA.

## Как это работает

**1. Скачать Excel → 2. Изменить → 3. Проверить → 4. Применить к TESSA.**

Никаких макросов в Excel не требуется. До нажатия **«Применить к TESSA»** скрипт только читает текущую матрицу и выбранный файл.

## Что умеет

- выгружать текущую матрицу TESSA в `.xlsx`;
- сохранять технические ID строк для точного сопоставления;
- изменять существующие строки;
- добавлять новые строки;
- распознавать вставку копии поверх другой строки как **замену целевой строки**;
- удалять строки, действительно удалённые из Excel;
- сопоставлять значения со справочниками TESSA;
- показывать diff `было / стало` до записи;
- блокировать опасные и неоднозначные операции;
- отображать прогресс длительных действий;
- сохранять JSON-отчёт после применения.

## Быстрый старт

Первичная установка выполняется один раз. Подробные шаги для **Chrome, Firefox, Edge, Opera, Safari и других Chromium-браузеров** находятся в [инструкции по установке](docs/INSTALL.md).

После установки:

1. Откройте нужную матрицу TESSA.
2. Нажмите **«Скачать Excel»**.
3. Измените лист **«Матрица»** и сохраните файл.
4. В Studio выберите этот файл и нажмите **«Проверить изменения»**.
5. Проверьте счётчики и строки `было / стало`.
6. Только после проверки нажмите **«Применить к TESSA»**.

Главные правила:

- **изменить строку** — изменить нужные ячейки существующей строки;
- **добавить строку** — вставить копию в новую свободную строку;
- **заменить строку** — вставить копию поверх существующей строки; Studio сохранит identity целевой строки и выполнит UPDATE;
- **удалить строку** — удалить существующую строку Excel целиком;
- несколько значений в одной ячейке вводить через `Alt+Enter`;
- скрытые ID вручную не менять;
- если в preview неожиданно появилось `УДАЛИТЬ`, ничего не применять и проверить файл.

Подробности: [Работа со Studio и Excel](docs/WORKFLOW.md).

## Кнопки Studio

| Кнопка | Для чего нужна |
|---|---|
| **Скачать Excel** | Обычная быстрая выгрузка текущей матрицы. |
| **Скачать со свежими справочниками** | Принудительно перечитывает справочники TESSA. Нужна, если значение недавно добавили или переименовали. |
| **Выбрать Excel** | Выбрать изменённый `.xlsx`. |
| **Актуализировать выбранный Excel** | Перенести пользовательские правки в актуальную структуру текущего шаблона TESSA. Обычно не требуется. |
| **Проверить изменения** | Построить diff. Ничего не записывает в TESSA. |
| **Применить к TESSA** | Записать только проверенный план. |
| **Отмена** | Остановить длительную операцию, если текущий этап позволяет это сделать. |

## Права

Скрипт **не выдаёт дополнительных прав и не обходит ограничения TESSA**.

Для применения изменений нужны:

- доступ к нужной матрице;
- штатные права на её корректировку;
- состояние/режим карточки, в котором TESSA разрешает редактирование.

Если прав нет, установка userscript их не добавит.

## Разрешения Tampermonkey

Сам userscript использует `@grant none`: он не запрашивает дополнительные Tampermonkey API. Скрипт запускается только на указанных доменах TESSA:

```text
https://tessa.cherkizovsky.net/*
https://tessa-app01.cherkizovsky.net/*
https://tessa-app01tl.cherkizovsky.net/*
https://tessa-app*.cherkizovsky.net/*
```

Для Chrome/Edge Tampermonkey 5.3+ может потребовать включить **Allow User Scripts** или Developer Mode — это требование самого Tampermonkey для выполнения userscripts в Chromium. Подробно и со скриншотами: [docs/INSTALL.md](docs/INSTALL.md).

## Обновление

В userscript настроены `@updateURL` и `@downloadURL` на этот репозиторий. После публикации новой версии Tampermonkey сможет получить обновление штатным механизмом.

Если автоматическое обновление запрещено политиками браузера, повторно нажмите кнопку **«Установить TESSA Matrix Studio»** в начале страницы.
