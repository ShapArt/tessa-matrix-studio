# Security

TESSA Matrix Studio выполняется в браузере текущего пользователя и не должен использоваться для обхода прав или ограничений TESSA.

## Что не следует публиковать в Issues

Не прикладывайте в публичные Issues:

- пароли, токены, cookies и заголовки авторизации;
- выгрузки с конфиденциальными данными;
- внутренние URL с чувствительными параметрами;
- персональные данные, которые не нужны для воспроизведения ошибки.

Для обычного bug report достаточно версии скрипта, браузера, описания шагов, обезличенного preview и текста ошибки.

## Уязвимости

Если проблема относится к безопасности, не публикуйте технические детали в обычном Issue. Используйте приватный канал сопровождения организации или приватное обращение владельцу репозитория.
