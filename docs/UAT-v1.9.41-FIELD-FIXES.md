# Проверка TESSA Matrix Studio 1.9.41

Установите userscript из ветки исправления и обновите вкладку TESSA. Проверьте версию 1.9.41. Все действия выполняйте в тестовой матрице; рабочий Excel скачивайте из Studio. FULL_RUNBOOK — отдельный чеклист, загружать его как матрицу не нужно.

## Что воспроизведено по исходным материалам

В исходном отчёте Apply было 13 успешных UPDATE и 3 исключённые строки: одна из-за двух ячеек количества листов, две из-за локального сравнения одинаковых подписей справочника при разных ID. Локальная реконструкция исходного snapshot и повторное чтение исходных XLSX воспроизвели те же счётчики 1.9.40.

С исправлением: 16 UPDATE, 2 NOOP, 0 ADD/DELETE/SKIP строк и 1 исключённое поле. При сравнении с выгрузкой после исходного Apply: 3 UPDATE, 15 NOOP; отдельная ячейка, которую Excel превратил в дату, остаётся исключённой. Это доказательство работы парсера и planner; серверный Store повторно не выполнялся.

## Короткий повторный прогон

| Проверка | Действие | Ожидаемый результат |
|---|---|---|
| Пустое количество листов | В свежей выгрузке заполнить ранее пустые «Основной» и «Приложения» как `4-15` и `2..10` | Ячейки текстовые; Preview показывает обе границы |
| Запись диапазона | Применить одну строку; нажать «Проверить результат» и скачать свежий Excel | verified; обе границы сохранены в TESSA и Excel |
| Ошибка одного поля | На копии рабочей книги ввести `ошибка` в «Приложения», одновременно изменить «Основной» и другое поле | UPDATE остаётся; «Приложения» отмечено как неприменяемое, текущее значение сохраняется |
| Отчёт о частичном наборе полей | Применить предыдущий UPDATE | В итоговом сообщении и `skippedFields` отчёта указано пропущенное поле; остальные поля записаны |
| Одинаковые подписи | Изменить две строки с одинаковой подписью, но разными ID значения справочника | Ложного локального дубля нет; штатная серверная валидация остаётся |
| Настоящий дубль | На копии книги сделать две строки действительно одинаковыми по ID и значениям | Конфликтующие изменения не применяются |
| Ошибка в новой строке | Новая строка с неверным диапазоном | SKIP всей новой строки |
| Ошибка единственного изменённого поля | Исправных изменений в строке нет | SKIP; пустой UPDATE не выполняется |
| Неверный файл | После успешного Preview выбрать FULL_RUNBOOK | Старый Apply недоступен; проверка объясняет, что выбран чеклист |
| Переименованный лист | Переименовать лист «Матрица» и поставить перед ним обложку | Рабочий лист определяется по метаданным |
| Устаревший Excel | Штатно изменить ту же строку TESSA после выгрузки, затем проверить изменённый Excel | Защита от устаревшего состояния остаётся |

Для ячейки, которая уже стала датой: задайте формат «Текстовый» и введите исходный диапазон повторно. `01.04.2015` не позволяет однозначно узнать, что было набрано первоначально.

Перед релизом записать результат живого прогона: версию, Preview, Apply, результат проверки и совпадение свежей выгрузки. Не считать проверку завершённой только по сообщению об успешном Store.
