## Замечания, которые не являются дефектами релиза

1. Отдельная read-only диагностика имеет `status=incomplete`, потому что она намеренно не выполняла запись (`writesAttempted=0`) и перечисляет непроверенные write-сценарии. Эти сценарии полностью пройдены соседним Full UAT ZIP.
2. Диагностический ZIP помечен `containsBusinessData=true` и содержит сырые карточки/ответы TESSA. Он является чувствительным служебным материалом. Обычный support ZIP таких тел не содержит.
3. Full UAT доказывает корректность клиента и записей текущей учётной записи. Серверный отказ `CardGet/CardNew/CardStore/Delete` для ограниченных ролей должен отдельно подтвердить владелец ACL TESSA.
4. «Максимально оптимизировано» не является конечным состоянием: новые браузеры, объёмы справочников и TESSA runtime могут изменить профиль. Регрессии фиксируют измеримые пороги и должны выполняться для каждого релиза.

По представленным данным блокирующих ошибок, незавершённых изменений, остаточных тестовых строк или повреждения матрицы не обнаружено.
