# UAT v1.17.1

Full UAT доступен только в exact UAT build (`npm run build:uat`) и показывается отдельной видимой кнопкой в разделе «Проверки и поддержка». Production build намеренно не публикует тестовый runner.

Регрессия 1.17.1 требует, чтобы временный ADD использовал вид документа из актуальной области `MtxRouteTemplate.CardTypeID`, support bundle создавался из изолированного UAT-контекста, а конфликтный merge всегда имел минимум три справочных значения. Каскадные `action-apply` и `action-reconcile` считаются пройденными только после реальных write receipts и read-back.

## Fast UAT — цель до 2 минут

Read-only сценарий на exact UAT candidate: открыть и закрыть панель, холодная/тёплая выгрузка, Preview на 100 и 3 000 строк, каждый фильтр мышью и клавиатурой, повторный клик «все», поиск длинного списка, отмена, восстановление после ошибки и один browser download пакета. PASS скачивания ставится только после распаковки ZIP, сверки manifest/SHA-256 и чтения трёх Excel.

## Live smoke

На тестовой матрице выполнить одну операцию каждого типа: ADD, UPDATE, DELETE и CLEAR. После Apply обязательно выполнить повторное чтение, reconciliation и восстановление исходного состояния. Cleanup ledger должен содержать ID созданных строк и доказательство удаления временных данных.

## Certification UAT

Перед релизом выполнить все поля и 65 write-операций. Отдельно проверить ограниченные учётные записи и серверные отказы `CardGet`, `CardNew`, `CardStore`, `Delete`. Допуск: `FAIL 0`; `NOT RUN` разрешён только с явной причиной и блокирует production gate для обязательного сценария.
