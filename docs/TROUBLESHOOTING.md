# Ошибки и частые вопросы

## Скрипт установлен, но кнопки в TESSA нет

Проверьте по порядку:

1. Tampermonkey включён.
2. TESSA Matrix Studio включён в списке userscripts.
3. Текущий адрес начинается с одного из поддерживаемых TESSA-доменов.
4. В Chrome включено **Allow User Scripts** либо требуемый для вашей версии режим, описанный Tampermonkey.
5. Tampermonkey имеет доступ к текущему сайту.
6. Обновите страницу TESSA.

Для Chrome 138+ Tampermonkey отдельно описывает переключатель **Allow User Scripts**: https://www.tampermonkey.net/faq.php?q=Q209

## Кнопка «Применить к TESSA» недоступна

Обычно это означает одно из трёх:

- Excel ещё не проверен;
- план заблокирован safety-проверкой;
- TESSA не разрешает запись из-за прав или состояния матрицы.

Скрипт не должен обходить права. У пользователя должны быть штатные права на корректировку матрицы.

## Появилось неожиданное удаление

Не нажимайте **«Применить»**.

1. Проверьте, не была ли существующая строка удалена или затёрта в Excel.
2. Если вставляли копию поверх строки, preview должен показывать **ЗАМЕНИТЬ**, а не случайный `ADD + DELETE`.
3. Если намерения удалить строку не было — скачайте свежий Excel и повторите изменение.

## Значение не находится в справочнике

Сначала попробуйте **«Скачать со свежими справочниками»**.

В Excel пишите фактическое название значения. Если одинаковое название существует несколько раз, используйте уточнённый вариант, который показывает выгрузка. Скрипт не выбирает один из неоднозначных справочников случайно.

## Что делать с «пропустить»

`ПРОПУСТИТЬ` означает, что строка не будет записана автоматически.

Причина показывается в preview. Исправьте Excel или данные TESSA и повторно нажмите **«Проверить изменения»**. Остальные корректные строки могут применяться отдельно только если общий safety-check не заблокировал план.

## Долгая загрузка

Для крупных матриц чтение строк и справочников занимает время. Смотрите на индикатор прогресса и текущий этап.

Не запускайте вторую такую же операцию параллельно в той же карточке.

## Ошибка во время применения

При ошибке скрипт скачивает файл вида:

```text
TESSA_Matrix_ErrorReport_*.json
```

Файл содержит техническую информацию о сбое и последние сообщения выполнения, но не заменяет проверку самой матрицы. Приложите его к обращению специалисту, который сопровождает матрицы.

## Excel не открывается или повреждён

Скачайте файл заново через **«Скачать Excel»**. Не сохраняйте рабочую книгу в старом формате `.xls` и не конвертируйте её через сторонние онлайн-сервисы.

## Автоматические обновления скрипта не приходят

Проверьте Site Access Tampermonkey. Официальная документация предупреждает, что ограниченный host access может мешать обновлениям userscripts: https://www.tampermonkey.net/faq.php?q=Q306

Также можно открыть главную страницу репозитория и повторно нажать кнопку установки — Tampermonkey предложит обновить уже установленный userscript.
