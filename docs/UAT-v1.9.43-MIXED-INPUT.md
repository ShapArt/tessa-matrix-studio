# UAT 1.9.43: смешанный ввод

Цель — применить корректные изменения из той же книги, где есть ошибки. Пропущенные строки и поля должны быть объяснены в Preview и отчёте. Повреждение структуры файла или чужой контекст остаются причинами блокировки записи.

## Готовая книга

`TESSA_UAT_MIXED_v1.9.43.xlsx` подготовлена по личной выгрузке пользователя `(11)`. Она передаётся отдельно: исходные значения, справочники и ID не публикуются в GitHub. Это рабочая матрица со служебными листами, а не отдельный чеклист.

Внутри: `Матрица`, `Инструкция`, `Старт проверки`, `Сценарии`, `Проверка ячеек`, `Действия вручную`. Служебные листы сохранены. Все статусы ручных проверок начинаются с `NOT RUN`.

| Ожидание до первой записи | Количество |
|---|---:|
| Изменить | 9 |
| Добавить | 3 |
| Удалить | 0 |
| Без изменений | 4 |
| Пропустить строки | 42 |
| Сохранить ошибочные поля существующих строк | 4 |

Эти числа относятся к исходной матрице на момент выгрузки. После частичного применения, внешнего изменения матрицы или правок книги нужен новый Preview; старые числа не являются разрешением обходить конфликт.

## Первый проход

1. Установить проверяемую сборку, открыть исходную тестовую матрицу и дождаться готовности без ручного повтора.
2. Выбрать книгу и нажать «Проверить изменения». Сверить числа и лист `Сценарии`.
3. Проверить строку 23: меняются все 26 рабочих полей. В строках 19–22 правильные поля меняются, четыре ошибочных поля сохраняют текущую TESSA.
4. Строки 24–28 содержат только ошибки и пропускаются. Новые строки 34, 35, 37 добавляются; 36 — дубль. Строки 33, 38 пустые и не создают операций.
5. Строки 39–64 проверяют неправильный ввод каждого из 26 полей. Строки 65–74 — ссылки, HTML/script, SQL, формулы, неизвестный элемент списка и длинный текст. Все эти новые строки пропускаются целиком.
6. На тестовой матрице применить 12 корректных операций. Проверка результата: `verified=12`, `divergent=0`, `unknown=0`. Сверить 468 исходных ячеек и три добавления со свежей выгрузкой. Старый план повторно не применяется.

SQL, DDE и HYPERLINK в книге — буквальный текст. Настоящие формулы только безвредные `=1+1`. Никаких макросов, исполняемых DDE-ссылок или внешних связей для тестирования не требуется.

## Отдельные действия на копии

Лист `Действия вручную` содержит проверки сортировки, вставки/очистки строк, удаления, копирования поверх существующей строки, изменения обеих копий с одинаковыми ID, удаления колонок, повреждённого baseline, чужой матрицы, повреждённого XLSX, конфликтов после Preview, остановки Apply и другой структуры шаблона.

Удаление проверяется на копии свежей выгрузки и тестовой матрице. В исходной смешанной книге удаления нет. Структурное повреждение ZIP/XLSX нельзя включить в успешно применяемый общий файл: нельзя доверять восстановленному набору операций.

## Интерфейс и Excel

- Новая выгрузка и готовая UAT-книга не показывают жёлтую input message при выборе ячейки. Списки остаются. Несколько значений: `Alt+Enter` либо выбор в Studio → копировать → в Excel `F2`, `Ctrl+V`. Правила находятся на листе `Инструкция`.
- Шрифт панели берётся из темы TESSA; запасной Gotham Pro Server уже присутствует в предоставленной выгрузке сайта. Скрипт не загружает внешние шрифты.
- Основные кнопки выделены красным; нажатие/открытие имеют короткую анимацию. При включённом уменьшении движения анимации отключены.
- Boolean в обоих столбцах Preview отображается как Да/Нет. Несколько элементов видны отдельно; повторяющиеся подписи не склеиваются и не удаляются. Для выбора точного одноимённого значения используйте квалифицированные варианты справочника.

Отключение сообщения сохраняет саму проверку данных: [Microsoft — Input and Error Messages](https://support.microsoft.com/en-us/excel/more-on-data-validation). Уменьшение движения: [W3C — CSS C39](https://www.w3.org/WAI/WCAG22/Techniques/css/C39).

## Автоматика и границы проверки

`tests/field-update-regressions.mjs` проверяет смешанный UPDATE/ADD/SKIP, сохранение отклонённого поля при реальном `rebuildRowCard`, формулы, неизвестные значения, экранирование Preview и XML экспортируемых validation rules. `tests/multi-template-roundtrip.mjs` проверяет три структуры и восемь типов значений. Полный `npm test` также покрывает ZIP/XML/OPC, races, DELETE, отмену, права/состояние, post-Apply refresh, reconciliation и нагрузки.

Сама ОРД-матрица содержит ReferenceGuid, ReferenceInt, Boolean, Int и функции. Date, DateTime, Decimal и String здесь не выдумываются; они проверяются автоматикой и живым UAT подходящего шаблона.

Сохранённая HTML-страница позволяет изучить стили и API-контракты, но не подтверждает живую серверную запись. Merge/release требуют зелёной автоматики и завершённого live UAT этой сборки.
