# Работа с TESSA Matrix Studio

Рабочая цепочка всегда одна:

**Скачать Excel → изменить файл → проверить diff → применить.**

Начинайте с текущей карточки нужной матрицы. Не используйте Excel от другой матрицы как основу для новой правки.

## Шаг 1. Скачать Excel

Откройте панель Studio:

<p align="center"><img src="assets/studio-panel.webp" width="500" alt="Реальная панель TESSA Matrix Studio"></p>

### Скачать Excel

Основная кнопка для обычной работы. Файл содержит:

- лист **«Матрица»**;
- лист **«Инструкция»**;
- справочные данные;
- скрытые технические идентификаторы строк.

Скрытые ID вручную не меняйте.

### Скачать со свежими справочниками

Используйте, если нужное значение недавно добавили или переименовали в TESSA и обычная выгрузка его ещё не видит. Это более тяжёлая операция, поэтому для ежедневной работы достаточно обычной кнопки **«Скачать Excel»**.

## Шаг 2. Изменить Excel

Реальный лист «Инструкция» из выгрузки Studio:

<p align="center"><img src="assets/excel-real-instruction.png" width="100%" alt="Реальный Excel из TESSA Matrix Studio"></p>

Редактируйте пользовательские колонки листа **«Матрица»**.

### Изменить существующую строку

Измените нужные ячейки и сохраните файл. Preview покажет **ИЗМЕНИТЬ**.

### Добавить новую строку

1. Вставьте новую свободную строку Excel.
2. Можно скопировать похожую существующую строку.
3. Вставьте копию именно в **новую строку**, а не поверх другой существующей.
4. Измените значения.

Preview должен показать **ДОБАВИТЬ**.

### Заменить существующую строку

Если скопировать одну существующую строку **поверх другой существующей строки**, Studio трактует это как замену цели.

Например:

- в Excel 67 была строка A;
- поверх неё вставили строку B;
- Preview показывает **ЗАМЕНИТЬ — Excel 67 → TESSA ...**;
- сохраняется identity строки, которая изначально находилась в Excel 67;
- в TESSA выполняется один UPDATE целевой строки.

Это сделано специально, чтобы итог TESSA соответствовал тому, что пользователь видит в Excel, без лишнего `ADD` и потерянной строки.

### Удалить строку

Удалите существующую строку Excel **целиком**.

Preview должен показать ожидаемое количество **УДАЛИТЬ**. Если удаление появилось неожиданно — не нажимайте «Применить», скачайте свежий Excel и проверьте правку.

### Несколько значений

Если поле допускает несколько значений, каждое значение размещайте на отдельной строке внутри одной ячейки. В Excel используйте `Alt+Enter`.

### Логические поля

Для логических признаков используйте **Да** / **Нет**.

## Шаг 3. Проверить изменения

1. Нажмите **«Выбрать Excel»**.
2. Выберите сохранённый `.xlsx`.
3. Нажмите **«Проверить изменения»**.
4. Дождитесь окончания прогресса.

На этом этапе Studio **ничего не записывает в TESSA**.

<p align="center"><img src="assets/studio-preview.webp" width="500" alt="Реальный preview изменений"></p>

Проверьте счётчики:

| Счётчик | Что означает |
|---|---|
| **изменить** | существующие строки с изменёнными данными |
| **добавить** | новые строки |
| **удалить** | существующие строки, действительно удалённые из Excel |
| **без изменений** | строки, совпадающие с TESSA |
| **пропустить** | строки, которые нельзя безопасно применить |

Раскройте изменённые строки и проверьте `было / стало`.

## Шаг 4. Применить

Нажимайте **«Применить к TESSA»** только после проверки preview.

Во время применения Studio показывает этап и прогресс. Перед записью критические условия проверяются повторно.

После завершения скачивается JSON-отчёт о применении. Сохраните его хотя бы до проверки результата в TESSA.

## Что делает «Актуализировать выбранный Excel»

Эта кнопка нужна редко. Используйте её, если после выгрузки Excel изменилась структура шаблона TESSA: появились новые критерии, функции или колонки.

Studio создаст актуальный файл и перенесёт пользовательские правки настолько, насколько это можно сделать безопасно. После этого снова выполните **«Проверить изменения»**.

## Перед применением

Проверьте шесть вещей:

1. Открыта правильная матрица.
2. Excel относится к этой матрице.
3. Количество `изменить / добавить / удалить` совпадает с тем, что вы делали.
4. Нет неожиданного `УДАЛИТЬ`.
5. Причины всех `ПРОПУСТИТЬ` понятны.
6. У вас есть права на корректировку этой матрицы.

Если хотя бы один пункт не сходится — не применяйте план.
