# Работа с TESSA Matrix Studio

## Сценарий целиком

![Сценарий](assets/workflow.svg)

Работа всегда начинается с текущей карточки матрицы TESSA. Не используйте старый Excel от другой матрицы как основу для новой правки.

## Шаг 1. Скачать Excel

Откройте нужную матрицу и панель TESSA Matrix Studio.

<p align="center"><img src="assets/studio-panel.webp" width="500" alt="Панель"></p>

### Скачать Excel

Основная кнопка. Используйте её в обычной работе.

Файл содержит:

- лист матрицы для редактирования;
- инструкцию;
- справочные данные для поиска значений;
- скрытые технические идентификаторы, по которым строки сопоставляются с TESSA.

Не редактируйте скрытые идентификаторы вручную.

### Скачать со свежими справочниками

Используйте, если нужное значение только что появилось или было переименовано в TESSA и обычная выгрузка его ещё не знает.

Это более тяжёлая операция, поэтому обычная кнопка **«Скачать Excel»** предпочтительнее для ежедневной работы.

## Шаг 2. Изменить Excel

Редактируйте пользовательские колонки листа **«Матрица»**.

![Пример выгрузки и изменений](assets/excel-example.svg)

![Правила Excel](assets/excel-rules.svg)

### Изменить существующую строку

Измените нужные ячейки и сохраните файл. Identity строки остаётся прежней, поэтому preview покажет **ИЗМЕНИТЬ**.

### Добавить новую строку

1. Вставьте новую строку Excel в свободное место.
2. Удобнее всего скопировать похожую существующую строку.
3. Вставляйте копию именно в **новую строку**, не поверх другой существующей строки.
4. Измените нужные значения.

Скрипт распознает копию как **ДОБАВИТЬ** и создаст новую строку TESSA.

### Заменить существующую строку

Если строку скопировали **поверх другой существующей строки**, это считается осознанной заменой цели.

Пример:

- в Excel 67 была строка A;
- на неё вставлена копия строки B;
- preview покажет **ЗАМЕНИТЬ — Excel 67 → TESSA ...**;
- техническая identity целевой строки A сохраняется;
- в TESSA выполняется изменение этой строки, а не бессвязный `ADD`.

Это позволяет получить итоговую матрицу, соответствующую Excel, без появления лишних строк.

### Удалить строку

Удалите существующую строку Excel **целиком**.

Перед применением preview обязательно должен показывать ожидаемое количество **УДАЛИТЬ**. Если удаление появилось неожиданно — ничего не применяйте, скачайте свежий Excel и повторите правку.

### Несколько значений

Если поле допускает несколько значений, каждое значение должно находиться на отдельной строке **внутри одной ячейки**. В Excel используйте `Alt+Enter`.

### Логические поля

Используйте понятные значения **Да** / **Нет**. Скрипт нормализует допустимые логические значения, но в пользовательском Excel лучше придерживаться именно этой формы.

## Шаг 3. Проверить изменения

1. Нажмите **«Выбрать Excel»**.
2. Выберите сохранённый `.xlsx`.
3. Нажмите **«Проверить изменения»**.
4. Дождитесь завершения индикатора прогресса.

На этом этапе запись в TESSA **не выполняется**.

<p align="center"><img src="assets/studio-preview.webp" width="500" alt="Preview изменений"></p>

Проверьте пять счётчиков:

| Счётчик | Значение |
|---|---|
| **изменить** | существующие строки с изменёнными данными |
| **добавить** | новые строки |
| **удалить** | строки, отсутствующие в Excel и подтверждённые как удаление |
| **без изменений** | строки, совпадающие с текущей TESSA |
| **пропустить** | строки, которые нельзя безопасно применить |

Затем раскройте изменённые строки и проверьте `было / стало`.

## Шаг 4. Применить

Нажимайте **«Применить к TESSA»** только после проверки preview.

Во время операции отображаются этап и прогресс. Скрипт повторно проверяет критические условия непосредственно перед записью.

После завершения автоматически скачивается JSON-отчёт о применении. Сохраните его до проверки результата в TESSA.

## Актуализировать выбранный Excel

Эта кнопка нужна не в обычной ежедневной работе.

Используйте её, если после выгрузки Excel изменилась структура самой матрицы TESSA: появились новые критерии, функции или колонки. Скрипт создаст актуальный файл и постарается перенести пользовательские изменения в новую структуру.

После актуализации заново запустите **«Проверить изменения»**.

## Перед применением

Минимальная проверка оператора:

1. Открыта правильная матрица.
2. Excel был выгружен из этой матрицы или актуализирован для неё.
3. Количество `добавить / удалить / изменить` соответствует намерению.
4. Нет неожиданных `удалить`.
5. `пропустить` либо равно нулю, либо причины каждой пропущенной строки понятны.
6. У пользователя есть права на корректировку матрицы.

Если хотя бы один пункт вызывает сомнение, не применяйте план.
